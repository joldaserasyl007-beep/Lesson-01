# 📱 Урок-01 — React Native / Expo

Учебный проект по разработке мобильных приложений с использованием **React Native** и **Expo**.

## 📖 О проекте

**Урок-01** — это учебный проект, созданный для изучения основ разработки мобильных приложений с помощью React Native и Expo.

Проект предназначен для практического освоения создания пользовательских интерфейсов, работы с компонентами, стилизации элементов и основных принципов разработки кроссплатформенных мобильных приложений.

## 🎯 Цели проекта

- Изучить основы React Native.
- Научиться создавать пользовательские интерфейсы мобильных приложений.
- Освоить работу с компонентами.
- Познакомиться с синтаксисом JSX и JavaScript/TypeScript.
- Научиться стилизовать элементы интерфейса.
- Изучить запуск и тестирование приложений с помощью Expo.
- Освоить базовую структуру проекта мобильного приложения.

## 🚀 Установка и запуск

Чтобы запустить проект на своём компьютере, выполните следующие действия.

### 1. Предварительные требования

Перед началом работы установите:

- [Node.js](https://nodejs.org/)
- npm (устанавливается вместе с Node.js)
- [Git](https://git-scm.com/)

Дополнительно можно использовать:

- [Expo Go](https://expo.dev/go/) — для запуска приложения на мобильном устройстве.
- Android Studio — для запуска Android-эмулятора.

### 2. Клонирование репозитория

```bash
git clone https://github.com/joldaserasyl007-beep/Lesson-01.git
```

### 3. Переход в папку проекта

```bash
cd Урок-01
```

Если папка проекта называется иначе, укажите её фактическое название.

### 4. Установка зависимостей

```bash
npm install
```

### 5. Запуск проекта

```bash
npx expo start
```

После запуска откроется Expo Development Server с QR-кодом и дополнительными командами.

### 6. Запуск приложения

Выберите удобный способ запуска:

- **На телефоне:** отсканируйте QR-код через Expo Go, если это поддерживается конфигурацией проекта.
- **На Android-эмуляторе:** нажмите `a` в терминале Expo.
- **В браузере:** нажмите `w`, если проект настроен для запуска в веб-браузере.
